### Cópia cifrada local (28/10/2026)

- Arquivo cifrado: `~/.local/share/caderno-backups/pre-juri-20261028-2339.tar.gz.enc` na máquina de publicação (modo 600, pasta 700). Cifra AES-256-CBC com PBKDF2 (200000 iterações) e salt.
- Chave: `~/.config/secrets/caderno-backup-chave.txt` (modo 600). Sem ela o arquivo não abre. A chave nunca vai para o repositório nem para arquivo versionado.
- Prova feita em 28/10/2026: o arquivo decifrado tem md5 `e8dacc06366eafe3d87e8c985ea12d23` (igual ao do servidor) e 194 entradas.
- Decifrar para um diretório de teste, nunca sobre o ar nem dentro do repositório:

```
umask 077; mkdir -m 700 $HOME/restauro-local-<data> && openssl enc -d -aes-256-cbc -pbkdf2 -iter 200000 -pass file:$HOME/.config/secrets/caderno-backup-chave.txt -in $HOME/.local/share/caderno-backups/pre-juri-20261028-2339.tar.gz.enc -out $HOME/restauro-local-<data>/backup.tar.gz

### Como voltar a versão (ensaiado na Fase 5.1, inclusive o passo 5, numa cópia)

Quem decide voltar a versão é o líder. Os passos 1 a 4 mexem no ar só no passo 3.

1. Guardar o estado atual, para poder refazer:
```
ssh hostinger 'umask 077; mkdir -m 700 $HOME/rollback-<data> && cp -a $HOME/domains/<dominio>/public_html/direito2026 $HOME/rollback-<data>/atual-antes'
```
2. Extrair só o site do backup, num diretório de trabalho:
```
ssh hostinger 'mkdir -m 700 $HOME/rollback-<data>/backup && tar -xzpf $HOME/backups-d26/pre-juri-20261028-2339.tar.gz -C $HOME/rollback-<data>/backup public_html/direito2026/'
```

O `-p` é obrigatório: ele mantém os modos do tar (644 nos arquivos, 755 nos diretórios). Sem ele, com `umask` restritiva, a extração deixa os arquivos em 600, e o site responde 403. Medido em 28/10/2026: 160 arquivos saíram em 600 sem `-p`.
3. Aplicar no ar. O `--delete` é obrigatório: sem ele, os arquivos da Júri (`api/juri/` e os assets novos) continuam no ar. Confira que o destino termina em `public_html/direito2026/` antes de rodar.
```
ssh hostinger 'date +%s%3N; rsync -a --delete $HOME/rollback-<data>/backup/public_html/direito2026/ $HOME/domains/<dominio>/public_html/direito2026/; date +%s%3N'
```
4. Conferir: 160 arquivos, com md5 igual ao do `backup/` extraído, e `api/juri` ausente. Modos: os dois comandos abaixo devem dar `0`. Com `curl`, `https://direito2026.<dominio>/api/saude.php` deve dar 200.
```

``` Para `https://direito2026.<dominio>/api/juri/conteudo.php`, anote o código que voltar: o ensaio não mediu o HTTP, e a rota da Júri deixa de existir. Ele só não pode mais dar 401.
5. Tirar a Júri de uso, sem apagar nada. Ensaiado numa cópia em 28/10/2026 (Fase 5.1). A execução no ar é decisão do líder:
```

```
A pasta `.desativado` continua com a conta e o acervo cifrado da Júri. Só pode ser apagada depois da sub-fase 5.3.
6. Se o líder também quiser reverter o código no repositório: `git revert 8be6e48`, que cria commit novo. Nunca `reset`. Isso não é necessário para devolver o ar à versão anterior.

Tempo: os ensaios mediram 94 e 172 ms para o passo 3 (160 arquivos). O tempo real também depende da rede. Meça de novo no dia, pelos dois `date` do passo 3.
